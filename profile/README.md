## About Us

Fouroam Dev was created to explore ideas, build practical software, and make development a collaborative process.

We care about **clear architecture, transparent development, accessible tools, and community contributions**. Our work is at an early stage, and we aim to document progress openly rather than advertise unfinished features as complete products.

Founded by [Athilio (@AthilioRecovery)](https://github.com/AthilioRecovery), the organization welcomes independent contributors and developers interested in taking a more active role in future projects.

## Our Projects

| Project | What it is | Status |
| :-- | :-- | :-- |
| **[Fouroam-V](https://github.com/Fouroam-Dev/Fouroam-V)** | Research-stage project exploring private, self-hosted cooperative experiences for up to four friends in GTA V. | Concept / pre-alpha |
| **[Fouroam Server](https://github.com/Fouroam-Dev/Fouroam-Server)** | Planned lightweight networking server for private LAN/VPN sessions, designed to be hosted on a player's own PC. | Planning / pre-alpha |

**Neither project currently provides a playable multiplayer build.** Planned capabilities are not a guarantee of technical feasibility, platform compatibility, or permission to distribute game modifications.

## How We Work

- **Open source:** Share original code and documentation with clear licensing.
- **Self-hosting first:** Prefer tools that people can run and control themselves.
- **Small, practical steps:** Build and test networking foundations before larger integrations.
- **Community-driven improvement:** Welcome thoughtful issues, code reviews, and pull requests.
- **Responsible development:** Respect third-party licenses, software security, and applicable platform rules.

## Contributing

You do not need to be an official organization member to contribute.

1. Choose a repository and read its `README.md`, `CONTRIBUTING.md`, and roadmap.
2. Check existing issues or open a discussion about a proposed change.
3. Fork the repository and create a focused feature or fix branch.
4. Implement and test your change, then open a **Pull Request** against `main`.
5. Respond to review feedback and help keep the change documented.

Start with [Fouroam-V](https://github.com/Fouroam-Dev/Fouroam-V) or [Fouroam Server](https://github.com/Fouroam-Dev/Fouroam-Server).

## Join the Team

We are also looking for **developers interested in contributing as official members of Fouroam Dev**, beyond submitting individual pull requests.

Experience with **C++, C#, .NET, networking, systems programming, or game development** is especially relevant. We value reliability, collaboration, and demonstrable technical work more than buzzwords.

To introduce yourself, include a short summary of your experience, your GitHub profile or portfolio, and the areas you would like to help with. Team membership is considered individually and is separate from public open-source contributions.
